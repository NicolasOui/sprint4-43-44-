# Автотесты для сервиса «Яндекс.Самокат»

Проект по автоматизации UI-тестирования сервиса заказа самокатов. Реализован на **Java** с использованием паттерна **Page Object**.

## Основные сценарии тестирования


| Область проверки                      | Описание                                                                                             | Особенности                         |
|:--------------------------------------|:-----------------------------------------------------------------------------------------------------|:------------------------------------|
| **Полный цикл заказа (E2E)**          | Прохождение всех этапов: заполнение всех полей выбор адреса, метро, даты и срока аренды.             | Тестирование до подтвержения заказа |
| **Выпадающий список (FAQ)**           | Соответствие ответов на 8 вопросов в разделе «Вопросы о важном».                                     | Параметризованный тест              |
| **Валидация формы (Негативный тест)** | Проверка сообщений об ошибках при некорректных данных и блокировка кнопки заказа (только поля со *). | Негативное тестирование             |
| **Логотипы и навигация**              | Переход на главную «Самоката» и открытие «Яндекса» в новой вкладке.                                  | Работа с окнами браузера            |
